## 🚀 Como rodar o projeto

```bash
npm install
```

### Ambiente de desenvolvimento

```bash
npm run dev:server   # inicia a API mockada do cliente
npm run dev:agent    # inicia o agente
```

### Build e execução (produção)

```bash
npm run build

npm run start:server # inicia a API
npm run start:agent  # inicia o agente
```

### Lint

```bash
npm run lint-fix     # formata o código
```
